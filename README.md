# 〰️ WaveStudio — Генератор звуковых волн на прозрачном фоне

**WaveStudio** — это удобное приложение для создания красивых анимированных аудио-волн из любого аудио или видеофайла. 

Программа анализирует частоты трека (бас, бочку и вокал) и генерирует **готовый видеофайл самой волны без фона (с прозрачным альфа-каналом)**, которая идеально ложится в бит музыки. Вы можете закинуть полученное видео поверх своих роликов, сниппетов, Reels, Shorts, подкастов или музыкальных обложек в любом видеоредакторе.

### ✨ Основные возможности

* **Прозрачный фон (Alpha-канал):** Экспорт в форматах `.MOV` (PNG Alpha / Apple ProRes 4444) и `.WEBM` (VP9), которые сразу готовы для наложения в Premiere Pro, CapCut, DaVinci Resolve, After Effects и др.
* **Точное попадание в бит:** Умное разделение частот на басовую линию и вокал с настраиваемой плавностью движения.
* **Разные стили и геометрия:** 
  * Линейная симметричная волна
  * Двухсторонняя (вокал сверху / бас снизу)
  * Круговая волна (активное кольцо 360° с реакцией на бас)
  * 4 режима анимации (*Live, Progress, Scroll, Spectrum*)
* **Гибкая кастомизация:** Готовые пресеты, двойные градиенты, настройка толщины, скругления, количества полос и размера.
* **Любые форматы кадра:** Поддержка 16:9 (Full HD / HD), 1:1 (Квадрат для обложек) и 9:16 (Вертикальное для Shorts / Reels / TikTok) в 30 или 60 FPS.
* **Работа с любыми медиа:** Просто перетащите в окно программы аудио (`.mp3`, `.wav`, `.flac` и др.) или видеофайл (`.mp4`, `.mov`, `.mkv`) — программа сама извлечет звук.

### 🚀 Скачать и запустить (Windows)

Устанавливать Python или дополнительные библиотеки **не нужно** — всё уже собрано в один файл:

1. Перейдите в раздел **[Releases](../../releases)** (справа на странице репозитория).
2. Скачайте последний архив / `.exe` файл программы.
3. Запустите `WaveStudio.exe`, загрузите трек, настройте волну по вкусу и нажмите **«🎬 Рендер видео»**.
